# Just One More

Site vitrine du studio **Just One More** — logiciels, jeux, contenu.

## En ligne 24/7

**URL principale (Vercel) :** https://justonemorestudio.vercel.app

Aussi : https://justonemore-gamma.vercel.app  
Instagram : https://www.instagram.com/justonemore.exe/

Republier :

```bash
npx vercel --prod --yes
```

## Dev

```bash
npm install
npm run dev
```

Ouvre `http://localhost:5173/`.

## Build

```bash
npm run build
npm run preview
```

## Stack

- Vite + React + TypeScript
- Identité : noir / ivoire / or soft (`public/brand/`)
- Hébergement : Vercel
